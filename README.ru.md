# PRA — Private Retrospective Analysis

> **Бета-версия** — проект находится в активной разработке. API, схема отчётов и workflows могут меняться без уведомления.

Приватный локальный ретроспективный анализ истории сессий Codex Desktop, [Claude Code](https://claude.ai/code) CLI и Hermes. Формирует отчёты на основе обезличенных метаданных о рабочих паттернах, повторяющихся исправлениях, качестве промптов и привычках верификации — **без раскрытия вставленного содержимого, секретов, исходного кода, названий проектов или локальных путей**.

## Поддерживаемые источники

| Источник | Расположение истории |
| --- | --- |
| Codex Desktop | `~/.codex/history.jsonl`, `~/.codex/sessions/*.jsonl`, `~/.codex/archived_sessions/*.jsonl` |
| Claude Code CLI | `~/.claude/history.jsonl`, `~/.claude/projects/*/*.jsonl` |

Все три источника можно анализировать одновременно с `--provider all`. Hermes читается из `$HERMES_HOME/state.db` в режиме read-only. Пользовательские JSONL-файлы можно передавать напрямую через `--source`.

Переменные окружения `CODEX_HOME` и `CLAUDE_HOME` заменяют стандартные пути (не суммируются).

## Поток данных

1. **Сырые JSONL** читаются построчно.
2. **`object_pairs_hook`** фильтрует заблокированные имена полей на этапе декодирования JSON. Блокируются: вставленный контент, буфер обмена, содержимое файлов, бинарные данные, изображения, base64-значения.
3. **Классификация событий** определяет пользовательские сообщения, ответы ассистента, результаты инструментов и записи прогресса.
4. **Обработка событий ассистента** локально декодирует структуру контента для обнаружения вызовов инструментов. Сохраняются только: timestamp, session (хеш), role, kind, has_tool_calls (булево), tool_content_available (булево). Текст ассистента, thinking, имя инструмента, входные и выходные данные инструмента **никогда не сохраняются**.
5. **Агрегация** вычисляет количество, длительность и паттерны из оставшихся метаданных.
6. **Markdown-отчёт** записывается на диск. Промежуточный обезличенный набор данных временный и удаляется после сохранения отчёта.

Никаких внешних сервисов, телеметрии или сетевых запросов во время анализа. Подробное описание приватности см. в [`references/privacy-model.md`](skill/pra/references/privacy-model.md).

## Требования

- **Python 3.10 или новее**
- **Ноль внешних зависимостей** — используются только модули из стандартной библиотеки Python.
- Для автопоиска через `--provider` необходима история Codex Desktop и/или Claude Code CLI на машине. Для `--source` подойдёт любой JSONL-файл.

## Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/chessclab/pra.git
cd pra

# 2. Создать директорию для отчётов (по умолчанию: ~/.pra/reports)
mkdir -p ~/.pra/reports

# 3. (Опционально) Установить как навык
#    Codex Desktop: скопировать или создать симлинк skill/pra в ~/.codex/skills/
#    Claude Code CLI: скопировать или создать симлинк skill/pra в ~/.claude/skills/
#    На Windows (cmd, от администратора):
#      mklink /D "%USERPROFILE%\.claude\skills\pra" "%CD%\skill\pra"
#    На Linux / macOS:
#      ln -s "$PWD/skill/pra" ~/.claude/skills/pra
#    Затем вызвать $pra внутри ассистента.
```

## Быстрый старт

Просмотреть, какие файлы будут проанализированы, без генерации отчёта:

```bash
python skill/pra/scripts/review.py --provider all --days 7 --dry-run
```

Запустить полную ретроспективу за последние 7 дней:

```bash
python skill/pra/scripts/review.py --provider all --days 7
```

Проанализировать конкретный JSONL-файл напрямую:

```bash
python skill/pra/scripts/review.py --source ./exported_history.jsonl --days 30
```

## Примеры

Проанализировать только Claude Code CLI за последние 3 дня:

```bash
python skill/pra/scripts/review.py --provider claude --days 3
```

Указать точный диапазон дат:

```bash
python skill/pra/scripts/review.py --provider codex --since 2026-06-01 --until 2026-07-01
```

Сохранить отчёт в произвольную директорию:

```bash
python skill/pra/scripts/review.py --provider all --days 7 --output-dir ./my-reports
```

## Известные ограничения

- **Нет мониторинга в реальном времени** — инструмент предназначен для периодического ретроспективного анализа, а не для живых дашбордов.
- **Нет HTML-экспорта** — отчёты только в Markdown и JSON.
- **Нет SQLite или базы данных** — каждый запуск самодостаточен.
- **Строгое сравнение** — отчёты сравниваются только при совпадении провайдера, режима источника и точной длительности периода. Отчёты схемы v3 читаемы, но не авто-сравниваются с v4. Явные пользовательские источники (`--source`) никогда не сравниваются автоматически.
- **Codex Desktop vs Claude Code CLI** — некоторые поля метаданных различаются между форматами; межпровайдерные отчёты используют пересечение доступных полей.
- **Нет конфигурационного файла** — все опции задаются флагами командной строки.
- **Переменные окружения** — `CODEX_HOME` заменяет `~/.codex`; `CLAUDE_HOME` заменяет `~/.claude`. Они не суммируются.
- **Поведенческие метрики приблизительны** — время ответа зависит от модели, инструментов, тестов и окружения. События ассистента на пользовательский ход могут не соответствовать логическим ответам один-к-одному.
